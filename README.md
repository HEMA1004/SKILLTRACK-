# SkillTrack 🎓💻

### Student Skill & Internship Tracker

SkillTrack is a web-based student productivity platform that helps students manage their skills, learning goals, internships, deadlines, and achievements in one place.

## 🚀 Features

- 🔐 Student Login
- 👤 Student Profile
- 💻 Skill Progress Tracking
- 🎯 Learning Goals
- 💼 Internship Tracker
- 🔎 Internship Search
- 📊 Dashboard Analytics
- ⚠️ Deadline Reminders
- 🏆 Achievement Badges
- 🌙 Dark Mode
- 📱 Mobile Responsive Design
- 💾 Local Storage Data Management

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
- Local Storage

## 🎯 Purpose

SkillTrack helps students organize their technical skills, internship applications, learning progress, and important deadlines through a simple and user-friendly dashboard.
